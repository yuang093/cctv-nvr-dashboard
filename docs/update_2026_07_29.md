### 9. `recording_status` — 24h 錄影完整率（Phase 2.8 Arisan）

記錄每台 cam 最近一次 `/timeline` 24h 視窗的完整率 + 缺段秒數。

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | INTEGER PK | |
| `nvr_id` | INTEGER NOT NULL FK→`nvr_servers.id` | |
| `camera_id` | TEXT NOT NULL | NVR 原始 deviceId |
| `window_start` | TEXT NOT NULL | 視窗開始（UTC ISO 8601） |
| `window_end` | TEXT NOT NULL | 視窗結束（UTC ISO 8601） |
| `completeness` | REAL NOT NULL | 0.0~1.0 完整率 |
| `missing_seconds` | REAL NOT NULL | 缺段總秒數 |
| `checked_at` | TEXT NOT NULL | 寫入時間（UTC） |
| `UNIQUE` | (nvr_id, camera_id) | 最近一次覆蓋 |

**索引**：`idx_recording_status_checked_at(checked_at DESC)`

**寫入時機**：worker 跑 `/timeline` 後（v2.8+ 待實作）
**讀取時機**：`/wall` 卡片 + `/devices/<id>` 詳細頁
